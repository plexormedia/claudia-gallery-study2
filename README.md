# claudia.gallery study copy

A study copy of the homepage of [claudia.gallery](https://claudia.gallery/), made to learn from its design.
Claudia by anabology. This is not the original site and is not affiliated with it.

This first commit holds the homepage's HTML, CSS and JavaScript exactly as claudia.gallery served them on 8 October 2026,
as a reference. The next commit adapts them to run on GitHub Pages; `git diff` between the two shows every change.
